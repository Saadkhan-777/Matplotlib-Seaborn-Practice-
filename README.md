# 📊 Matplotlib & Seaborn Data Visualization Practice

A streamlined repository demonstrating exploratory data analysis, customized charting, and data storytelling using **Matplotlib** and **Seaborn** in Python.

---

## 👤 Author
- **Saad Khan** | Computer Science & Data Science

---

## 🎯 Overview
This repository contains practical exercises and real-world data visualization projects, including a case study analyzing Sachin Tendulkar's career run progression using time-series graphs and statistical plots.

---

## 🛠️ Tech Stack
- **Language:** Python 3.x
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook

---

## ⚙️ Quick Start

```bash
# Clone the repository
git clone [https://github.com/Saadkhan-777/Matplotlib-Seaborn-Practice-.git](https://github.com/Saadkhan-777/Matplotlib-Seaborn-Practice-.git)
cd Matplotlib-Seaborn-Practice-

# Install dependencies
pip install numpy pandas matplotlib seaborn jupyter

# Launch Jupyter Notebook
jupyter notebook
```

---

## 📓 Notebook Highlights

1. **Environment & Theme Configuration:** Setting up clean visual presets using `sns.set_theme()`.
2. **Matplotlib Fundamentals:** Customizing figure dimensions, markers, line styles, gridlines, and legends.
3. **Sports Analytics Case Study:** Tracking cumulative runs, performance trends, and key career milestones using Seaborn line and bar charts.

## 💡 Key Takeaways
- **Matplotlib** offers fine-grained control over layout and individual plot elements.
- **Seaborn** simplifies statistical visualization with built-in themes and color palettes.
- Thoughtful axis labeling, titles, and legends make complex data accessible and engaging.
